# Aedis Keycloak

Secure-by-construction Keycloak: a hardened, optimized image with the Aedis SPIs, a Helm chart with safe defaults, a
hardened baseline realm with FAPI 2.0 on by default, and SAST and DAST running against the installed model, kept on
the latest Keycloak patch.

Not an official Keycloak distribution and not endorsed by the Keycloak project.

Status: design only. The target is in [docs/design.md](docs/design.md); the image, chart and realm land by pull request.
